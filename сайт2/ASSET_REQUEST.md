# ASSET REQUEST — что нужно для фильма уровня референсов

Сейчас в проекте референсы 418–635 px с запечённым текстом и AI-банками. Они задают композицию, но на весь экран не растягиваются. Ниже — чистые исходники, из которых собирается фильм: камера по скроллу «пролетает» сквозь сцену с настоящей глубиной (плейт + карта глубины + передний план), а между мирами идут физические переходы по STORYBOARD.md.

Общие правила для всех изображений:
- **Без текста, логотипов, интерфейса, людей и без банок** (банки вставляются отдельно — настоящие, чтобы этикетки были точными).
- Композиция и свет — как в соответствующем референсе из `moonvit_all_assets_png`.
- Формат: **PNG** (лучше 16 бит) или JPEG качества 95+. Конвертацию в AVIF/WebP делаю сам.
- Главный объект держать в центральной зоне ~60% ширины, чтобы из того же кадра получилась вертикальная мобильная версия. Если композиция не позволяет — отдельный кадр 2160×3840.

## P1 — фильм на главной (без этого премиального уровня не будет)

### 1. Миры — по одному комплекту на Hero, Luna, Saturn, Venus, Mars, Earth, Neptune (7 шт.)

| Слой | Размер | Что это |
|---|---|---|
| `<world>_plate.png` | 3840×2160 | Чистый кадр мира. Место под банку оставить пустым (там, где банка стоит на референсе). |
| `<world>_depth.png` | 3840×2160, 16-бит grayscale | Карта глубины того же кадра: белое — близко, чёрное — далеко. Можно получить из плейта через Depth Anything v2 / Marigold. Нужна для объёмного пролёта камеры. |
| `<world>_fg.png` | 3840×2160, прозрачный фон | Передний план отдельно: камни, край воды, скалы, которые проходят перед банкой и перед камерой. |
| `<world>_fog.png` (по желанию) | 3840×2160, прозрачный фон | Туман / дымка / пыль отдельным слоем. |

Референсы: Hero — `01_hero_main`, `S01`; Luna — `02`, `S02`; Saturn — `03`, `S04`; Venus — `04`, `S06`; Mars — `05`, `S08`; Earth — `06`, `S10`; Neptune — `07`, `S12`.

### 2. Переходы (5 шт.) — `S03`, `S05`, `S07`, `S09`, `S11`

Лучший вариант — **короткие видео**: 3–4 с, 1920×1080 (лучше 2560×1440), MP4 H.264 **all-intra** (каждый кадр ключевой, `-g 1`), чтобы видео можно было проматывать скроллом вперёд и назад. Начало клипа совпадает с последним кадром мира «до», конец — с первым кадром мира «после».

Если видео нет — плейт 3840×2160 без текста для каждого перехода: золотая рябь на воде, световые потоки, облако красной пыли, туман над мхом, толща воды с пузырьками.

### 3. Финал (`S13`) и выбор мира (`08`, `S15`)

- `final_horizon_plate.png` 3840×2160 — край планеты снизу со светом звезды, **без** планет в ряд.
- Шесть планет **по отдельности**: `planet_luna.png` … `planet_neptune.png`, 2048×2048, прозрачный фон, свет слева-сверху (Saturn — с кольцами). Одни и те же файлы идут в финальный reveal (планеты появляются по очереди: Neptune → … → Luna) и в блок «Что тебе нужно сегодня?».

### 4. Банки

- Нужны фронтальные фото/рендеры **Luna, Saturn, Earth, Neptune** в 3840×2160 с прозрачным фоном (как уже есть у Mars и Venus в `Documents/Codex/.../work/*-pack.png`). Банка в кадре ≥ 1600 px по высоте.
- По желанию — ракурс 3/4 и вид чуть сверху для каждой из шести: тогда банка в каждом мире стоит в своей перспективе (DESIGN_SYSTEM: «разный масштаб, перспектива и глубина»).
