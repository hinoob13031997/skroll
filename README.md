## Где сайт и как он публикуется

- Репозиторий: https://github.com/hinoob13031997/skroll — это сам проект (исходники), а не копия готовых страниц.
- Сайт: https://hinoob13031997.github.io/skroll/ (главная — пролёт по шести мирам, галерея — `/gallery/`).
- Каждая отправка в ветку `main` запускает `.github/workflows/pages.yml`: GitHub собирает сайт (`node build.mjs`), проверяет его (`node check.mjs`) и публикует. Если проверка не прошла, живой сайт не меняется. Ход сборки — вкладка Actions репозитория.
- Под адрес `/skroll/` пути переписывает сам `build.mjs` (переменная `BASE_PATH`); канонические ссылки и sitemap берутся из `SITE_URL`. Локально без этих переменных сайт собирается для корня `/`.
- В git: код, тексты, документы `сайт2/*.md` и готовые веб-картинки `dist/assets/`. Остальное в `dist/` — результат сборки, в git не хранится. 4K-мастера, видео, исходные плейты (`сайт2/assets/`) и скриншоты-референсы в корне остаются только на этом компьютере (см. `.gitignore`).

## Запуск

Нужен Node.js 20 или новее. В терминале откройте папку `moonvit`:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Устанавливать зависимости не требуется.

После изменения исходников:

```sh
npm run build
npm run check
npm run dev
```

Если сервер уже запущен, достаточно пересобрать сайт и обновить страницу. Остановить сервер: Ctrl+C. Другой порт задаётся через переменную окружения `PORT`.

## Галерея — «нырок» и стена миров (`/gallery/`)

Разметка — `content/gallery-home.mjs`, логика — `src/gallery.js` (WebGL2), стили — блок «Gallery» в `src/styles.css`.

- Первый экран — кадр `film/hero.webp`, приветствие по времени суток: ночью «Уже поздно. Время замедлиться», утром, днём и вечером свои фразы. Первая прокрутка — камера ныряет в свет звезды, тёплая вспышка.
- Из вспышки появляется изогнутая стена: шесть кадров миров с банками на внутренней стороне цилиндра. В центре крупно текущий мир, соседние выглядывают по краям. Стена начинается с мира времени суток (ночью Luna, утром Saturn, днём Earth, вечером Venus).
- Прокрутка, свайп или список справа поворачивают стену. Она мягко останавливается на ближайшем мире, а во время поворота кадр слегка «переливается». Мышь чуть наклоняет камеру, за кадром огромное название мира.
- Под кадром фраза человеческим языком («Хочу спокойно уснуть»), название мира и категория. Фразы — `phrases` в `content/gallery-home.mjs`.
- Клик по кадру: мир разворачивается из своей рамки на весь экран (кадр, эффект, вкус, формула, приём, покупка, соседние миры). «← Все миры», Esc или «Назад» сворачивают его обратно. Прямые ссылки: `/gallery/#luna` … `/gallery/#neptune`.
- Без WebGL2, при выключенном движении или `prefers-reduced-motion` миры стоят друг под другом карточками со ссылками.
- Для телефона нужны вертикальные сцены: `сайт2/VERTICAL_PROMPTS.md`, исходники квадратов — `сайт2/assets/vertical/`.
- Скриншоты без открытого браузера: `node tools/shot.mjs <папка> 1440x810 http://127.0.0.1:4173/ scroll:1.9 shot:saturn` (headless Chrome).

## Главная — путешествие по мирам (`/`)

Версия, с которой снят ролик. Старый адрес `/voyage/` перенаправляет сюда (вместе с `#vg=…`). Финал «Найти свой мир» и «Пропустить полёт» ведут к мирам галереи (`/gallery/#worlds`).

Главная открывается полноэкранным путешествием: hero → Luna → Saturn → Venus → Mars → Earth → Neptune → вся система → «Что тебе нужно сегодня?». Сцена закреплена, прокрутка двигает камеру: каждый мир немного «отдыхает» с текстом, затем следующий раскрывается кругом из точки, где стоит банка, а предыдущий продолжает приближаться. Справа — навигация по мирам.

- Кадры — `dist/assets/film/{hero,luna,saturn,venus,mars,earth,neptune,final}.webp` (2880×1620, из 4K-мастеров `*_3840x2160.png` в корне проекта). Уменьшенные копии 1280 px — `dist/assets/{мир}.webp` для карточек.
- Между мирами — кадры пути (`сайт2/assets/plates/path_{мир}.png` → `dist/assets/film/path-{мир}.webp`): открытый космос с планетой следующего мира. Порядок: hero → путь к Луне → Luna → путь к Сатурну → Saturn → … → Neptune → финал. В космосе камера всё время летит к планете, ближние астероиды разлетаются, при быстром скролле звёзды вытягиваются в линии; затем камера ныряет в планету и открывается мир.
- Переходы разные (шейдер, `uKind`): из мира в космос — темнота и звёзды в линии; в Луну и Землю — туман; в Сатурн — золотое кольцо проходит через объектив; в Венеру — жемчужный свет; в Марс — фронт красной пыли; в Нептун — камера проходит сквозь поверхность воды; из hero — свет звезды.
- «Пропустить полёт» (внизу справа во время полёта) и «В начало ↑» (после полёта) переносят сразу, без перемотки всего фильма. Финальный кадр «Шесть миров. Один ты.» держится ~70svh прокрутки, затем уезжает вверх вместе со страницей; прокрутка вверх отматывает фильм назад.
- Объём — карты глубины `dist/assets/film/depth/{мир}.webp` (Depth Anything V2 Small, `tools/depth.py`; venv с PyTorch — `%LOCALAPPDATA%\moonvit-depth`). Шейдер проходит лучом по карте глубины: в покое камера медленно облетает банку и следует за мышью, ближние скалы сдвигаются относительно дальней планеты. Перелёт — к звезде/планете мира, её свет раскрывается вспышкой и прячет смену мира. Большие пролёты из одного кадра невозможны (за банкой нет изображения) — для них нужны фоны без банки или видео: `сайт2/IMAGE_PROMPTS.md`, `сайт2/VIDEO_PROMPTS.md`, папки `сайт2/assets/*`.
- Пролёт между мирами (21 сцена): hero → открытый космос (`cruise-a`) → подлёт к Луне → Luna → **проход мимо планеты, которую покидаем** (`pass-*`) → подлёт к следующей (`path-*`) → мир … → Neptune → открытый космос (`cruise-b`) → финал. Кадры — `сайт2/assets/plates/{cruise,pass,path}_*.png` → `dist/assets/film/*.webp`, глубина — `tools/depth.py`. В космосе камера не ныряет в точку, а идёт по маршруту (`move` в `space()` в `src/voyage.js`): смотрит на точку `a`→`b`, плавно приближается, закладывает крен; ближние астероиды уходят быстрее дальних, пролетаемая планета поворачивается (`orbit` в `ORBS`). Проход и подлёт склеены «по планете»: следующая планета при смене кадра остаётся на том же месте экрана и того же размера, у Марса и Земли это ещё и один и тот же вращающийся глобус (`LINK`). За краем космического кадра — зеркальное продолжение неба, а не растянутые пиксели. Каких двух кадров не хватает — `сайт2/IMAGE_PROMPTS.md`, раздел 0б.
- Живые планеты (`ORBS` в `src/voyage.js`, диски измерены `tools/limbs.py`). Луна, Марс и Земля — настоящие сферы: под светом кадра (терминатор, ореол, цвет сцены остаются из кадра) непрерывно проворачивается реальная карта поверхности (`dist/assets/space/p0-moon`, `p3-mars`, `p4-earth` + облака `earth-clouds`). У Сатурна, Венеры и Нептуна по широтам текут облака и полосы самого кадра, каждая широта со своей скоростью. Планету можно раскрутить мышью или пальцем — она вращается по инерции и постепенно возвращается к своему темпу. Кольца, вода, горы и банка перед диском не затрагиваются.
- Банку можно повернуть (`CAN`): тянешь вбок — этикетка едет по цилиндру (силуэт вращающегося цилиндра не меняется, поэтому свет на краях остаётся на месте), отвернувшийся край уходит в тень, отпущенная банка «тяжёлой» пружиной возвращается лицом к зрителю. Без касания она слегка покачивается и поворачивается вслед за мышью. Поворот ограничен ~25°: на кадре есть только передняя половина этикетки. Полный оборот на 360° требует развёртки этикетки или съёмки банки с разных сторон.
- Кольца Сатурна и марево Марса больше не искажают банку и ближние скалы (маска глубины + контур банки); рисованные 2D-«камни» убраны.
- Скриншоты: `/#vg=<сцена>[,<время с>[,<поворот банки, рад>]]` открывает мир в покое в заданный момент (например `#vg=path-earth,30`).
- Разметка — `content/cinema-home.mjs` (точки фокуса кадров и положение текста задаются там же), логика — `src/voyage.js`, стили — блок «Voyage» в `src/styles.css`.
- Без JavaScript, при `prefers-reduced-motion` или выключенном в footer движении сцены стоят друг под другом как обычные полноэкранные секции.
- Шрифты всего сайта: Cormorant Garamond (заголовки) и Manrope (текст), Google Fonts.
- Под путешествием — выбор состояния, ритуал, линейка настоящих банок, отзыв, три карточки.

Запуск без Node (Python): `py -m http.server 4173 --directory dist`, затем http://127.0.0.1:4173/. Через `file://` главная не оживёт (WebGL-текстуры).

## Состав проекта

- `build.mjs` — генерация всех HTML-страниц, метаданных, sitemap и robots.txt.
- `content/products.mjs` — единый каталог, названия миров, описания и каналы покупки.
- `content/products-source.json` — опубликованные исходные составы и описания Moonvit для аудита. В интерфейсе используются отредактированные описания.
- `content/legal-source.json` — снимок юридических текстов источника.
- `src/styles.css` — дизайн, адаптивные размеры и reduced-motion fallback.
- `content/cinema-home.mjs` — сценарий непрерывного главного экрана: вступление, шесть миров и финал.
- `src/app.js` — кинематографичная scroll-driven камера, canvas-эффекты, меню, выбор состояния и подготовка писем.
- `dist/assets/` — локальные WebP: оригинальные банки с прозрачным фоном, космические сцены и атмосферный слой.
- `server.mjs` — локальный сервер статических файлов с корректным 404.
- `check.mjs` — проверка внутренних ссылок, изображений, SEO, структуры и исправлений составов.
- `CONTENT-AUDIT.md` — источники, исправления и неразрешённые вопросы.
- `QA.md` — выполненные проверки и их границы.

## Архитектура и производительность

Кадры фильма — 4K-мастера из корня проекта (`01_hero_3840x2160.png` … `08_final_reveal_3840x2160.png`), сжатые до 2880 px в `dist/assets/film/`. WebGL2-шейдер в `src/voyage.js` оживляет каждый кадр: дрейф и крен камеры, параллакс, рябь воды, течение колец и жидкости, поворот планет, туман, марево, водопад, пульсирующая звезда, мерцание звёзд, световой блик по банке, частицы каждого мира. Перелёт: камера улетает в планету/звезду мира (точка `dive` в объекте `LIFE`), следующий мир раскрывается оттуда же. На широких экранах кадр сдвинут вправо (`pan`, `z`), чтобы банка стояла справа от текста. Планеты в блоке «Что тебе нужно сегодня?» — фотокарты Solar System Scope (CC BY 4.0) в `dist/assets/space/`, исходники в `assets-src/planets/`; подпись с авторством — в подвале. Без WebGL2 работает упрощённая CSS-версия.

Оригинальные банки Moonvit не перерисованы: этикетки, названия и дозировки сохранены пиксель-в-пиксель. Удалён только исходный тёмный фон, а единый вид создают цветной контровой свет, отражения, глубина, зерно и оттенок каждой планетарной сцены. Так упаковка остаётся достоверной и не выглядит вклеенной.

Поддерживаются `prefers-reduced-motion` и ручное отключение движения в footer. Основная навигация, составы и покупка работают без JavaScript. Без JavaScript интерактивный выбор показывает Luna; все шесть продуктов доступны через каталог. Картинки ниже первого экрана загружаются лениво, размеры зарезервированы, hero имеет preload и fetchpriority.

## Публикация на собственном домене

Перед сборкой задайте `SITE_URL` равным HTTPS-origin вашего сайта без завершающего слеша. Например в PowerShell:

```powershell
$env:SITE_URL = 'https://moonvit.space'
npm run build
npm run check
```

Разместите содержимое `dist/` на статическом хостинге. Нужны directory index, собственная 404 и HTTPS. `_headers` и `_redirects` подходят для Cloudflare-совместимого статического хостинга; на Nginx/другом сервере перенесите правила вручную. Здесь сохранены редиректы старых `/news`, `/b2b`, `/delivery`, `/offer`, `/privacy`, `/agreement`, `/details`.

Конфигурация `.openai/hosting.json` привязана к созданному Sites-проекту. Не переносите её в чужой Sites-проект без замены идентификатора. Секретов и токенов в проекте нет.

## Реальная функциональность

- Ozon и Wildberries ведут на конкретные существующие товары из старого сайта.
- «Moonvit» в покупке ведёт в нужную карточку официального каталога. Оплата и наличие обслуживаются действующим магазином, а не этим frontend.
- Формы Contacts и B2B валидируют поля и готовят `mailto`-письмо. Отправку подтверждает посетитель в своей почтовой программе; есть копирование текста. Нет backend, сохранения заявок, CRM, фиктивного success-сообщения или передачи данных без действия пользователя.
- Аналитика и рекламные cookies не подключены. В localStorage хранятся настройка движения и выбранные комплексы «Моего набора».

## Перед коммерческим запуском

Frontend готов к статическому размещению. Для окончательного утверждения продуктового и юридического контента нужны данные бренда: дозировка B12 Venus, основа расчёта активных дозировок, актуальные полные этикетки/аллергены/ограничения, сертификаты, проверенная редакция юридических документов, актуальные цены и наличие. Неизвестные значения не выдуманы. Подробности — в `CONTENT-AUDIT.md`.

Файл визуального master из предыдущего чата не был доступен; постановка воссоздана по сохранённому утверждённому описанию и дополнена единым атмосферным слоем. Все изображения без людей, настоящие этикетки сохранены.
